# Manual de Usuario — Sistema Veterinario

Este manual explica cómo usar el sistema para registrar y consultar clientes y sus mascotas.

## 1. Inicio

Al abrir el sistema se muestra la página de **Inicio**. Desde el menú superior puede entrar a **Clientes** y **Mascotas**.

## 2. Consultar Clientes

1. Haga clic en **Clientes** en el menú.
2. Se muestra la lista de propietarios registrados, con su teléfono y correo.

## 3. Buscar Cliente

1. En la página **Clientes**, escriba en el cuadro de búsqueda un nombre, teléfono o correo.
2. Pulse **Buscar**.
3. Para volver a ver todos los clientes, pulse **Limpiar**.

## 4. Registrar Cliente

1. En **Clientes**, pulse **Nuevo cliente**.
2. Llene el formulario con nombre, apellidos, teléfono, correo y dirección.
3. Los campos obligatorios deben completarse y el correo debe tener un formato válido (por ejemplo, nombre@correo.com).
4. Pulse **Guardar**.
5. El sistema regresa a la lista y muestra un mensaje de que el cliente se registró.

## 5. Editar Cliente

1. En la lista de **Clientes**, pulse **Editar** en el cliente deseado.
2. Modifique los datos necesarios.
3. Pulse **Guardar**. Se mostrará un mensaje de confirmación.

## 6. Ver Detalle Cliente

1. En la lista de **Clientes**, pulse **Ver**.
2. Se muestran sus datos completos y las mascotas que tiene registradas.

## 7. Ver Mascotas de un Cliente

1. En la lista de **Clientes**, pulse **Mascotas** en el cliente deseado.
2. Se muestran solamente las mascotas de ese propietario.

## 8. Consultar y filtrar Mascotas

1. Haga clic en **Mascotas** en el menú.
2. Se muestran todas las mascotas con su especie, raza, sexo y propietario.
3. Use los botones **Todas**, **Perros** o **Gatos** para filtrar por especie.

## 9. Registrar Mascota

1. En **Mascotas**, pulse **Nueva mascota**.
2. Elija el **propietario** de la lista. Si no aparecen propietarios, primero debe registrar un cliente.
3. Llene nombre, especie y los demás datos (raza, sexo, fecha de nacimiento, color y señas particulares).
4. La fecha de nacimiento no puede ser una fecha futura.
5. Pulse **Guardar**. Se mostrará un mensaje de confirmación.

## 10. Editar Mascota

1. En **Mascotas**, pulse **Editar** en la mascota deseada.
2. Modifique los datos y pulse **Guardar**.

## 11. Ver Detalle Mascota

1. En **Mascotas**, pulse **Ver**.
2. Se muestran el nombre, propietario, especie, raza, fecha de nacimiento y color.

## 12. Reglas de eliminación

Para proteger la información, el sistema no permite eliminar ciertos registros:

- **Un cliente que tiene mascotas registradas no se puede eliminar.** Primero deben eliminarse sus mascotas.
- **Una mascota que tiene consultas registradas no se puede eliminar.**

Para eliminar un registro:

1. Pulse **Eliminar** en el cliente o la mascota.
2. Revise la confirmación y pulse **Eliminar**.
3. Si el sistema no lo permite, mostrará un mensaje explicando el motivo y solo podrá pulsar **Regresar**.

## Mensajes del sistema

- **Mensaje verde:** la acción se realizó correctamente.
- **Mensaje amarillo:** hay un aviso o un error. Léalo y corrija el dato indicado.
